<h3>Linux on ESP32-S3</h3>
<p>
<a href="https://github.com/paulneja/Linux-on-esp32-S3">

<b>Linux 6.11 booting natively on Xtensa.</b> No emulation layer:
NOMMU, 16 MB flash, 8 MB PSRAM, Wi-Fi support, and the ESP32-S3

</p>
<p>Delivered as one flashable image for real hardware.</p>

<p>
<a href="https://github.com/paulneja/Zevory-Linux">
<img src="https://img.shields.io/badge/view_repository-1F6FEB?style=for-the-badge&logo=github&logoColor=FFFFFF" alt="View Zevory Linux repository" />

</p>
<p>
<b>An independent Linux distribution built from upstream source.</b>
Rolling release, Wayland-first, with a custom init and
package-management roadmap.

reproducible clean-clone build path.

<h3>Syscage</h3>
<p>
<a href="https://github.com/paulneja/Syscage">
